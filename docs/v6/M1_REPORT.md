# M1 想象体检与自检统计（部分）

## 本步问题

用全部可用候选检验“准入只看可见面，能否分辨好坏想象”；坏想象定义看结果前冻结为
`|rear_err| > 5 cm` 或 `path_p95 > 80 mm`。

## 命令

- `python3 scripts/v6_m1_eval.py`
- `python3 scripts/v6_m1_selfcheck.py`

## 未做到

- WP3 ±25° 的 96 份未评：渲染放置与每视角 V/U/真值未补齐，KA6 未在新沙箱验证。
- 因此 122 不是 S3 要求的全集；本统计只能作为部分结果。
- v3 有 9 份候选失联，未包含。

## 根因

- ±25° 缺的是“每视角自己的 V/U/真值”和可复现渲染；旧沙箱丢失了 WP3 crops 与部分状态资产，
  新沙箱只迁了 3 个状态，无法在 M1 内补齐 8 岩石×2 视角。
- 准入低特异度是真实结果：只看可见面确实难以排除后缘偏短的候选，不是统计错误。
