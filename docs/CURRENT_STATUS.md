## 一、v3 主问题的当前回答

主比较：同一状态、同一公共观测几何、同一冻结栅格，**FULL = V ∪ (生成父候选 ∩ 未知区)**
对 **OBS_ONLY = V**（逐体素同一个数组）；两臂各自从同一个 S0 恢复到同一真值场景独立执行。

| FULL 更好 / OBS_ONLY 更好 / 相同 | **1 / 0 / 13** |
| 风险低估 / 过度保守 | 0 / 0 |

隐藏区误差（有度量的 6 个候选-状态行，2 mm 栅格）：
隐藏占据 IoU 均值 0.011、漏填率 0.989、过填率 0.552；沿路径顶面 MAE 36.3 mm、P95 217 mm；
后缘位置误差 48 mm、后坡落差误差 3.3 mm。

唯一的那次差异：`moon_rock_04_h1v0`，FULL 选 R2（慢速）真值通行，OBS_ONLY 选 L2 真值物理失败。

**读法**：本批唯一方向性信号是“FULL 在 1 个状态上避免了 OBS_ONLY 的物理失败”，
但生成出来的隐藏几何与真值隐藏区几乎不重合（漏填 99%）。
因此**不能**把这一次胜利当成“隐藏几何被理解对了”；它更可能是“多出来的体块让策略绕开了真值失败”的副作用。
结论按当前规模：**支持“没有变差”，不支持“显著改善”**；需要更多状态与更严格的再观察才能定性。

   消融只删 U∩P，之后**不做**组件清理/补洞/闭合/重贴地/换栅格。

   旋转 2.11° / 0.86°、表面 p95 6.27 / 4.51 mm，两者 pass=True；
   单视角光滑正面存在沿面滑动歧义（已记录，不掩盖）。

4. **决策**：候选级预演矩阵 → 多数票（≥⌊n/2⌋+1）→ 预登记代价最低；
   相同几何只算一票、任务分母保留（n_tasks / n_unique_geometries 逐状态记录）；
   决策先原子落盘并记 SHA，再执行。
