# Gate P：同正面、不同背面（受控重跑）

## 几何（已修）

`scripts/twins.py` 改为**高度场棱柱**，并把正面采样从整体采样里独立出来：

| 项 | 结果 |
| --- | --- |
| 90 个双胞胎（3 种子 × 5 背面 × 3 高度 × 2 宽度） | 全部 watertight，非流形边 **0** |
| 正面顶点集合（x≤0） | 5 种背面**逐顶点一致**（2960 顶点、37 排、md5 相同） |
| 背面体积 | drop 0.0035 / ramp_s 0.0056 / ramp_l 0.0206 / ledge 0.0200 / cleft 0.0179 m³ |

> 早期版本的正面会随背深改变采样排数（drop 36 排、ramp_l 16 排），
> 那样"同正面"根本不成立；现在正面由 `front_rings` 独立生成并被原样复用。

## 碰撞（已修）

新增 `scripts/physicalize.py`（process_posed）：**不** rest_pose、**不**重新缩放、
**不**走近凸替换，直接对世界坐标网格做 CoACD。90 个资产全部成功，0 失败。
cleft 得到 3 个凸块（旧路径会替换成单凸包，槽被填平）。

## 受控重跑（`runs/unseen/gate_p/w4/`，810 回合）

修正了上一版的三处实验缺陷：

| 缺陷 | 上一版 | 本版 |
| --- | --- | --- |
| 障碍位置 | 放在 x=0，与机器人出生点重合 | 放在 **x=1.8**，与观测案例同一接近场景 |
| 初态 | 扰动为 0，三个 seed 是同一轨迹 | 横向 ±0.05 m、朝向 ±0.03 rad，**三个 seed 三条轨迹** |
| 碰撞 | 单凸包 | CoACD 多凸块（保留凹部） |

### 结果

| 验收 | 要求 | 上一版 | **本版（受控）** |
| --- | --- | --- | --- |
| P1 最优选项随背面改变 | ≥4/18 | 1/18 | **2/18 未通过** |
| P2 R1 一背全成功、另一背全失败 | ≥3/18 | 9/18 | **1/18 未通过** |
| P3 同正面观测一致 | 必须 | MAE 3.23 未过 | 未重测（见下） |
| P4 30 回合重演 | 必须 | 未做 | **30/30 一致，通过** |

**P2 从 9/18 掉到 1/18。** 之前那个数是被"三个 seed 其实是同一初态"和
"单凸包碰撞"共同抬高的，不能作为"仅背面变化导致通行差异"的证据。
本版才是受控结果。

### 判读

- 唯一稳定出现的是：`drop` 背面在 2 个正面配置上让 **L1（抬前腿慢过）** 成为最优，
  而其余背面都选 R1。这说明"背面确实能改变动作选择"在极少数配置下成立。
- 但**不足以称为 Gate P 通过**：18 组里只有 2 组。
- P3 仍未通过（未重测）：上一轮最好 MAE 3.23，根因是背面未按方案每侧内缩 2 cm。
  本轮修了正面独立与碰撞，但**没有**做内缩，因此 P3 预期仍不过。

## 下一步（两轮物理调整的第一轮）

1. P3：给背面加每侧 2 cm 内缩 + 肩部遮挡，重测同观测（目标 MAE<2、深度差<2 mm）。
2. P1/P2：按方案把高度档扩到 {1.4, 2.1, 2.8}×轮半径已做，但当前动作库只有
   R1/R2/L1/L2/S1/D1/D2/A0 中的三档真正参与矩阵；需要把 S1/D1/D2 纳入并验证可执行，
   才能让"最优选项"有更多分歧空间。这是**待验证的假设**，不是结论。
