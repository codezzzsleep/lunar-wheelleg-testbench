### 资产管线（可复用）

`GLB → 朝向校正 → 尺度归一 → 落地 → CoACD 拆凸块 → 几何量入库`

当前：**7 个生成资产**（boulder / cargo_crate / lander_leg / flat_slab / fallen_panel / crate_lid / debris_plate）
+ 22 个程序化对照 = **29 个已处理资产**。

管线上有三个关键修复（都是踩坑后发现的）：
1. **MuJoCo 对闭合网格按凸包碰撞**，凹槽会被"盖上"——CoACD 是必需的，不是优化。
2. **Lux3D 输出的网格不是水密的**，所以凹度改用「凸块体积和 / 凸包体积」，凸包用 manifold3d 算。
3. **朝向不受控**：扁平物体若按原始朝向竖着归一，会变成 2 米高的墙（rel_h 24.5）。改为"最稳定姿态落地"。

### 考场运行器

- 单次仿真约 1.5 秒；4 核并行
- **接触闸门**：没碰到障碍物的仿真判为无效，不计成绩
- 失败分类：完成 / 倾覆 / 卡住 / 超时
- 批量跑：`python scripts/batch.py`

### 三个考生（这是"轮腿"的核心）

| 考生 | 行为 | 本质 |
| --- | --- | --- |
| `hold` | 锁死站姿 + 轮速伺服 | 四轮小车，腿不参与 |
| `step` | 被挡住时：前腿缩短 + 后腿伸长，抬头压上台面 | 开环固定动作 |
| `adapt` | **只用本体感觉**（轮速 / 机体倾角 / 前进速度）判断"抬腿还是加大力矩" | 闭环决策，不读障碍物真值 |

`step` 和 `adapt` 都在 **1.51 倍轮半径**这一档把通过率从 **5% 提到 24%**——腿确实有用，但只在很窄的一档。

## 三、困难

### A. 方法层面（真正的瓶颈）

**1. 我用错了难度度量，整个比较从根上不公平。**
我用「包围盒高度 / 轮半径」分层。但包围盒对圆钝、带斜面的物体**系统性高估**难度。
最直接的证据：

| 相对高度 1.76 | 通过率 | 机器人平均抬腿次数 |
| --- | --- | --- |
| 生成的着陆器支架（躺倒的圆柱） | 17% | **0.00 次** |
| 同包围盒高度的方块 | 7% | **1.07 次** |

同宽同高，一个轮子顺着曲面就滚过去了，一个必须把轮子抬过棱。
**所以"同尺寸"这个前提本身就不成立**，换成"最大局部台阶高度"才是对的。

**2. 统计功效不够。** 每格 n≈7–14。要可靠检测 10 个百分点的差异，每格需要 n≈30 以上，
那意味着几十个资产、几千次仿真。

**3. 我把问题问错了。** 就算尺子修好、样本加够，最可能的结果仍是"在同等**有效**难度下两组无显著差异"。
因为**难度是几何决定的，与几何是程序化生成的还是模型生成的无关**。
生成模型的优势在"能造出程序化词汇表里没有的东西"，不在"同样的东西更难或更容易"。

**4. 连续三次判断失败。** 我说"下一步给考生加腿就能测出"，加了没测出；
说"下一步闭环就能测出"，闭环了还是没测出。这个模式本身说明问题问法有问题。

### B. 工程层面

| 问题 | 影响 |
| --- | --- |
| 只有 7 个生成资产 | 目标 ≥30 个，撑不起分层统计 |
| 障碍物是焊死的静态体 | 真实残骸会滚动/翻倒，现在不会 |
| 无 GPU | Isaac Sim / Isaac Lab 出局；Kaggle 免费 T4 同样无 RT 核心 |
| 环境不稳 | 上一轮 DSH 主进程退出，带走全部子进程，丢了 3 个待生成资产 |
| 依赖在 `/tmp` | `/tmp/robolib`、`/tmp/sysroot` 重启即失效，没写安装脚本 |
| PyPI 极慢 | 约十几 kB/s，装 jax 这类大包不现实（apt 源反而有 1.4 MB/s） |
| ffmpeg 残缺 | 这份构建缺 `image2` 和 `libx264`，只能出 GIF，出不了 MP4 |

### C. 我自己的错误（需要你知道）

1. **三次测量错误，都曾让结论完全失真：**
   - 只按高度归一 → 32/50 次仿真**根本没碰到障碍物**，却被记成"完成"
   - 扁平物体竖着归一 → rel_h 算出 24.5
   - 没有接触闸门 → 通过率被系统性抬高
   第一版表格显示"生成组 86% vs 方块组 0%"，**完全是假的**。
2. **成本控制失误**：前期 18 次生成全用 G1 最贵档（20 积分/次，合计 360），
   连跑通管线的冒烟测试也用 G1。其实 Turbo 只要 13 积分、71 秒。
3. **代码债**：`report.py` 已被 `analyze.py` 取代但没删；`gate1.py` 硬编码资产路径；`probe_go2w.py` 是一次性脚本。
