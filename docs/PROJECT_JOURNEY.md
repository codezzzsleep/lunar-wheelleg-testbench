## 1. 资产物理化与机器人通行考核（2026-10-25 → 10-26）

- **想解决**：Lux3D 生成的资产能不能进物理仿真、机器人能不能通过。
- **方法**：月球重力 + 碰撞对照 + 脚本控制器；同尺寸对照实验；给考生加腿（step 状态机）。
- **产物**：`submit/f253e2c`（阶段0/第1关）、`ceec1ba`（同尺寸对照 + 能力曲线）、
  `86e867f`（step 把 1.51 倍轮半径通过率 5%→24%）、`e858138`（收入 7 个 Lux3D 原始资产）。
- **得到**：资产能进仿真；包围盒高度**不是**难度主因（`19e90f1`）。
- **被修正**：早期「尺寸决定难度」的直觉被数据否掉。
- **为什么下一步**：单靠脚本控制器无法在陌生几何上泛化 → 转向学习与生成场景。
- **等级**：A（脚本与资产在仓库）。

## 2. 生成场景辅助训练与「程序化 vs 生成」对照（2026-10-26）

- **想解决**：生成资产是否比程序化资产更能提升学习。
- **方法**：M0 训练闭环；PPO 两个实现错误的数值验证与修复；条件化环境（米制地形、按地形落地）。
- **产物**：`e57d281`（M0，学习未成立）、`7347599`（修 PPO 两处错误）、`defce6f`（条件化环境）、
  `f7ed3a4`（单技能 20%→46%，**陌生家族考核未通过**）、`8b503f5`（六家族物理化，学习收益未成立）。
- **得到**：训练能跑通，但**收益不成立**；同家族提升、陌生家族失败。
- **被修正**：「生成资产 → 训练收益」这条链不成立。
- **为什么下一步**：不再指望端到端策略，改为「行动前推演」——用观测去约束候选几何。
- **等级**：A + B（报告与提交在仓库；部分训练产物在 `runs/`，不入库）。

## 3. 训练器修复与训练收益不稳定（2026-10-26）

- **想解决**：训练不稳定究竟是实现错误还是任务设定问题。
- **方法**：逐项数值验证（PPO 两处错误）、批次隔离、异常记录、输入校验、路径解析、来源证据。
- **产物**：`7347599`、`4a1640f`（第二轮六项修复）、`659c1c7`（结果可信度六项）、
  `1fe0828`/`cb018a0`（环境快照必须在创建运行目录**之前**拍，否则 `git_dirty` 自污染）。
- **得到**：实现错误修完后收益仍不稳定 → 不是（只是）实现问题。
- **被修正**：一次被自污染的批次（`canonical_r2`）**作废并移出版本控制**，保留记录。
- **等级**：A（修复提交 + `docs/TRAINER_REPORT.md`）。

## 4. 转向「部分观测下的行动前推演」（2026-10-27）

- **想解决**：只看得到障碍正面时，能不能先推演再行动。
- **方法**：Gate P 物理门（正面独立、真实初态、多凸块碰撞、自动判定）；五步页面；端到端闭环。
- **产物**：`1517137`（Gate P 实验基础）、`52469d2`（五步页面 + 端到端闭环）、
  `22e8f80`（统一动作执行器：L1 真触发、A0 真刹车、场地边界）。
- **得到**：链路能跑；Gate P 部分成立（P2 9/18），P1/P3 未过。
- **被修正**：双胞胎网格非流形 → 凸包替换**抹平了背面差异**，物理门本身失效（`docs/unseen/PHASE_P.md`）。
- **为什么下一步**：必须接真实图生，否则「隐藏背面」无从谈起。
- **等级**：A。

## 5. 真实图生、相机与配准的多轮排查（2026-10-27 → 10-28）

- **想解决**：真实 Lux3D 候选能不能与观测配准。
- **方法**：图生客户端/预算锁/账本；1024 观测裁剪；标定物；配准评估改用渲染深度差分；
  相机快照/恢复修正；24 朝向搜索；`align-metric/v2`。
- **产物**：`367c899`（unseen v1 + 图生链路）、`35d2261`（上传→create→轮询→ZIP 解 GLB）、
  `d650399`（真值自对齐 IoU 0.99）、`2c20e75`（修前视相机 90° 滚转）、
  `dbcd951`（相机快照/恢复修正，单候选 IoU 0.0077→0.9448）、`a38680d`（定位 43 mm 残差）、
  `1e362ed`（align-metric/v2）、`500b176`（修 MuJoCo 网格缓存污染）。
- **得到**：配准可达 0.94+；但 **19 个真实候选 0 个通过**（`1ecbb94`）。
- **被修正**：很多「模型不行」的结论实际是**相机、缓存、清理器**的问题，逐条被推翻重写。
- **等级**：A。

## 6. 动作接口、观察位与状态续接（2026-10-27 → 10-28）

- **想解决**：机器人在预演里能不能真的执行动作、能不能移动后重新观察并续接状态。
- **方法**：统一动作注册表；行驶观察位状态机；观察后继续执行；完整状态合同。
- **产物**：`97c9d3b`、`02a9f12`（观察未达标如实记录）、`ac99035`（观察位 10/10 可用）、
  `7033797`（「第二观测→筛选→新状态预演→决策→真值续行」）、`0da4aef`（统一阶段预算/终止/成本口径）。
- **得到**：观察位可用；第二观察链路能跑通。
- **被修正**：「观察不可用」是取景几何与转向控制问题，不是观测本身不可行。
- **等级**：A。

## 8. V6：观测约束融合、预测误差与碰撞不可靠（2026-10-29）

- **想解决**：把观测到的可见面作为约束，融进生成父候选，能否提升决策质量。
- **方法**：H5-F（生成父候选 + 观测约束）、B3-F（镜像父候选 + 同一融合器）、
  同真值同初态 30 s 匹配比较、预测审计、真实第二观察、静态土壤测量、连续回放页、绑定校验器。
- **产物**：`7d6610a`、`f6b301b`、`2f596fe`、`2e13773`、`6c35a15`、`4109128`；
  批次 `runs/unseen/delivery_v6/v6_20261029/manifest.json`；状态 `docs/UNSEEN_STATUS_V6.md`；
  页面 `runs/unseen/delivery_v6/v6_20261029/media/replay/index.html`；
  校验 `…/verify/report_v6.json`（33/33）；单测 130 项。
- **得到**：
  - H5-F 可见几何 strict pass（5 mm：IoU 0.9475 / P95 2.82 mm / free 0.0376）；
  - **CoACD 32/64 占据 IoU 0.2837 / 0.2861 → `COLLISION_UNRELIABLE`**；
  - 预测审计发现 1 个 false-safe（L2 seed0 预测 6.10 s 成功，真值 30.02 s 超时）；
  - 真实第二观察触发 S1 vs A0，两者均保留 → worst-case 选 A0 → 真值 A0 中止、R1 倾覆；
  - 静态土壤：`stable_ok`，公式下陷 9.75 mm vs 实测 −0.893 mm；整机几何下陷未实现。
- **被修正**：「H5-F 的 S1 成功」不能归因于隐藏几何——因为碰撞体不忠实（过填）。
- **为什么下一步**：几何与碰撞两层都要先修，才谈收益 → V6.1。
- **等级**：A。
