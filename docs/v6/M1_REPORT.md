# M1 想象体检全集与自检统计

## 本步问题

用全部可用候选检验“只看可见面的准入，能否分辨好坏想象”；坏想象定义为
`|rear_err| > 5 cm` 或 `path_p95 > 80 mm`，在统计前冻结于 `configs/v6_protocol.json`。

## 命令

- `python3 scripts/v6_m1_merge_full.py`
- `python3 scripts/v6_m1_selfcheck.py`
- 每视角：`python3 scripts/v6_m1_view_eval.py --rock <rock> --view <±25>`
- 渲染与配准全部在沙箱执行，checkup 拉回本地后合并。

## 未做到

- 每个 ±25° 视角的 KA1/KA5/KA6 未单独跑；本轮只保证有该视角自己的 V/U/真值，
  未做逐视角已知答案回归。
- 218 份中 12 份缺 rear/P95，未计入统计。
- v3 仍有 15 个丢失任务（9 v3 + 6 C2）不在全集内。

## 根因

- 准入低特异度是真实结果：可见面壳相接好、轮廓吻合，并不保证背面后缘正确；
  通过组中位 rear −16 mm，但 P75 已到 +8 mm，长尾里仍有 −13 cm 的坏想象。
- ±25° 的 V/U 由渲染深度+相机逐视角重建，不是原状态 fusion；这是“每视角自己的参照”的近似，
  逐视角 KA 缺失是下一轮要补的验证。
