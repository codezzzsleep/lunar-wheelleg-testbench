# 只保留生成隐藏面的 C1：单独预演与执行

C1 是六个候选里**唯一** `kept_ratio = 1.0`（保留 74,846 个生成隐藏体素、removed 0）的候选，
也是可见面最差之一（IoU 0.806 / P95 31.9 mm）。

同状态、同快照、同 nominal 规划、同 30 s 预算：

| 项 | 值 |
| --- | --- |
| 决策 | **D2** |
| 预演格 | 7（单土壤 × 7 动作） |
| 真值执行 | **通行** |

## 意义

- 这是本批**第一个**"生成隐藏面被保留、且规划与执行都成功"的样本；
- 但它不能单独证明生成先验有贡献，因为 C1 的可见面未过验收（IoU 0.806 < 0.85）；
- 与另外五个候选（可见面较好、隐藏面被全部雕刻）合起来看，形成了清楚的对照：

| 组 | 可见面 | 生成隐藏面 | 结果 |
| --- | --- | --- | --- |
| A1/A2/B2/C2 | 未过 | 全被雕刻 | 单候选 L2 通行（靠观测几何） |
| **C1** | 未过（最差） | **全部保留** | **D2 通行** |
| B1 | 融合后 IoU 0.906 | 全被雕刻 | 未单独执行 |

## 结论

生成隐藏面**保留与否**都可能在真值上通行，因此本批的通行结果**无法区分**"观测约束几何"与
"生成先验几何"的贡献。要分离这两者，需要：
1. 同一状态、同一观测，构造"只用观测壳层"的对照几何（无生成面）单独预演；
2. 与 C1（保留生成面）、A1（生成面被删）三者并列比较。

这是下一步，不需要新增生成。
