# WP6 抬身跨越提速报告

- 目标：ref、len_short、len_long 的 BODY_CLEARANCE 统一终点 ≤40 s，机身接触 0。
- 结果：三个场景均 **11.78 s、0 接触、pass**（原 113–117 s）。
- 计划：speed 0.4 m/s、ramp 40 步、lower_at 1.165 m（len_short 同计划也通过）。
- 公平性：提速后的同一计划供 FULL/OBS/PERFECT 使用；PERFECT 仍为 D2 7.28/7.24 s，
  因此信息价值差从约 106 s 缩小到约 4.5 s，后续报告不得再引用旧慢基线。
- 证据：`runs/v4/wp6/ref_s0.4.json`、`len_short_s0.4.json`、`len_long_s0.4.json`。
