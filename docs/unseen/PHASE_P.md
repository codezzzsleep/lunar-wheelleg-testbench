# Gate P：同正面、不同背面

## 几何（`scripts/twins.py`，已修好）

上一版非流形（27–48 条边）导致 `process_asset` 回退凸包、背面差异被抹平。
本版改为**高度场棱柱**：每个 (x,y) 给高度，上表面三角化 + 下表面 z=0 + 四侧壁缝合。

| 指标 | 结果 |
| --- | --- |
| 90 个双胞胎（3 种子 × 5 背面 × 3 高度 × 2 宽度） | **全部 watertight，非流形边 0** |
| 背面体积差异 | drop 0.0036 / ramp_s 0.0056 / ramp_l 0.0090 / ledge 0.0087 / cleft 0.0077 m³ |

碰撞约定（如实标注）：MuJoCo 对闭合网格按**凸包**碰撞；`process_asset` 仍会
`near_convex_hull_substituted=true`。因此 cleft/ledge 的凹部在碰撞中**不表现**，
它们的差异只来自凸包外形。本 Gate 的结论只在这个前提下成立。

## 见证矩阵（`runs/unseen/gate_p/w2/`，810 回合）

18 正面 × 5 背面 × 3 动作（R1 直行 / R2 慢压 / L1 抬前腿）× 3 初态。

| 验收 | 要求 | 实测 | 结论 |
| --- | --- | --- | --- |
| **P1** 最佳选项随背面变化 | ≥4/18 | **1/18** | **未通过** |
| **P2** R1 在某背面全成功、另一背面全失败 | ≥3/18 | **9/18** | **通过** |
| **P3** 同正面观测量一致（RGB MAE<2/255、深度差<2 mm） | 必须 | 最好 **MAE 3.23**（俯角 −3°、机位 z=0.171）；原机位 MAE 40–48 | **未通过** |
| **P4** 30 回合重演 | 必须 | 未做 | 未完成 |

### 怎么读

- **背面确实改变动作成败**（P2 9/18）：同一正面、同一初态，R1 在 ledge 上全失败而在
  ramp_s 上全成功。
- **但没有改变"最优选项"**（P1 1/18）：只要 R1 能过，它通常也是最快；备选动作很少赢。
  也就是说，当前动作库的差异不够大，稳健选择几乎总是选 R1。
- **P3 不成立**：背面在同一机位下仍可见。根因明确——生成器对正反面用了**同一个横向宽度剖面**，
  没有实现任务书要求的"背面每侧内缩 ≥2 cm"，短背面在侧缘露出轮廓。
  最好机位（俯角 −3°、接近脊线高度）把 MAE 压到 3.2，仍未达 2.0 阈值。
