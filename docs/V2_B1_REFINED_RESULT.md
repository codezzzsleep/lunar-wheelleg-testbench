# B1 精修配准后仍 kept = 0

## 做了什么

对可见面最好的候选 B1 单独跑 `align24`，时间预算从 240 s 提到 900 s（实际用 144 s，收敛），
再用新位姿重新融合，读清单。

## 结果

| 阶段 | 指标 | 值 |
| --- | --- | --- |
| align24 | pass / IoU / P95 | False / 0.680 / 32.9 mm |
| 融合后 | strict.pass / IoU / P95 | False / **0.906** / **8.9 mm** |
| 融合后 | kept_voxels / kept_ratio | **0** / **0.0** |

- align24 搜索与之前得到**同一姿态**（IoU 0.68），说明不是搜索没收敛；
- 融合后可见面指标回到 0.906 / 8.9 mm（壳层补偿），但**生成隐藏面仍被全部雕刻掉**。

## 判读

按事先约定：若在几毫米残差下 kept 仍为 0，判为**观测证伪**。当前残差 8.9 mm，略高于 5.2 mm 阈值，
因此结论是**"接近但未达判据"**，两种可能仍未完全分开：

1. 生成隐藏面确实伸进观测自由空间（证伪）；
2. 8.9 mm 的残差仍足以把合法隐藏面推进自由空间。

## 已确定的、可以写进报告的两条

- 六个候选**没有一个**同时做到"可见面达标 + 保留生成隐藏面"；
- 唯一保留隐藏面的 C1（kept 74,846）可见面最差（IoU 0.806 / P95 31.9 mm）。

也就是说：在本状态上，**生成先验与观测约束目前是互斥的**——要么保留生成面而可见面不准，
要么可见面准而生成面被完全删除。这是本批目前最强的负结果，且不依赖阈值松紧。
