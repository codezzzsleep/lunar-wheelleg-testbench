# v2 现状与下一步（给下一次继续用）

## 已经确定的（可直接写进报告）

1. **土壤集合效应**：A（三档最坏）6/21 vs B（当前 nominal）11/21，恢复 P06·S2(R1)、P58·S1(D2)、
   P76·S1/S2/S3(D1)。B 是"已知当前土壤"诊断。
2. **土壤估计不可辨识**：单位与驱动力模型修正后，μ、b 均贴边界、区间数百宽，不用于规划。
3. **配准是上一阶段的关键缺陷**：旧"缩放+固定放置"候选 IoU 0.59–0.71；
   `align24` 对真值网格 0.953 / 3.1 mm 通过，证明链路正确。
4. **融合清单是准入依据**：六个候选在 P06·S1 全部 `strict.pass=False`，
   五个 `kept_ratio=0`（生成隐藏面被 free-space 雕刻）。
5. **保留率依状态而定**：P58·S2 的 A1/C1 都保留（96k / 1.24M）。
6. **壳层足够支撑通行**：P06·S1 壳层几何选 L2 通行，C1（保留生成面）选 D2 通行 →
   可行性由观测壳层支撑，生成先验未显现增量。
7. **P58·S2**：A1（IoU 0.790，保留 96k）选 A0 停车；C1（IoU 0.920，保留 1.24M）选 D2 通行。

## 必须做的下一步

1. **P58·S2 壳层对照**（唯一能分离"可见面质量"与"生成先验"的实验）：
   用 C1 的观测壳层、去掉生成体素，构造对照几何，同快照同预算再跑一次。
   构造方法：从 `fused/occ.npz` 中移除 `retention` 归类为"生成贡献"的体素，或直接用观测壳层重新膨胀。
2. **P06·S3 补跑**：融合脚本里观测路径写错（`grid/P06/P06/S3/obs`），修好后重跑 A1/C1。
3. **主表字段**：Lux3D 行必须带 `strict.pass`、`kept_ratio`、`shell_control_outcome`。
4. **生成输入链路**：`aiPredictSize` 归一化与裁剪-相机对应，是"生成隐藏面能否过验收"的上游原因。
