### 关键发现：`a[2] = −1` 不是停车

| 操作 | 结果 |
| --- | --- |
| 巡航 0.85 m/s | 基线 |
| `a[2] = −1` 持续 2 s | **仍有 0.324 m/s** —— 旧接口没有刹车 |
| 显式刹车（轮速目标 0，增益 6） | **0.000 m/s**，刹停距离 0.679 m |

因此任务书要求的"真正的停车/刹停接口"必须在 `skills.py` 里实现为显式刹车，
不能把 `a[2]=-1` 当停车用。这一条已作为 A0（放弃）动作的实现依据。
