# C3 用 C0 方法重评 WP3 模型（yaw 0 子集）

## 本步问题

用列填实、每场景自己的 V/U/真值、只在 U 内比较的隐藏指标，重评 WP3 已返回的 Lux3D GLB；
给出每份候选的准入与想象质量，并做 N2 异常检查。

## 命令

- `python3 scripts/v5_c3.py`（8 个岩石 × yaw0 × 6 份 = 48 份）

- 同一岩石内 raw/white/masked 差异小，说明主导误差来自候选本身而非输入变体。

## N2 异常检查

- `moon_rock_01` 6 份候选 path_p95 全为 143.0 mm；`rock_07` 5 份全为 153.621 mm。
- 查因：机器人车道内的未知列上候选几何为空（Hc 为空），误差恒等于真值高度，
  因此 path_p95 恒等；不是脚本重复计算。两份岩石的隐藏 IoU 也低（0.38–0.52），
  与“未填进未知区”一致。记录在 `checkup.json`，不改门槛。
