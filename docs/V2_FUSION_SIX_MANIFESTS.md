## 关键结论

1. **六个候选全部 `strict.pass = False`**：没有任何一个通过可见面验收（阈值 IoU ≥0.85 且 P95 ≤5.2 mm）；
   B1（IoU 0.906）与 C2（0.870）IoU 达标，但 P95 分别 8.9 / 14.6 mm，仍未过；
2. **五个候选 `kept_ratio = 0`**：融合把生成的隐藏几何**全部丢弃**，`no_generated_hidden_contribution = True`；
3. **只有 C1 保留了生成隐藏面**（kept_ratio 1.0），但它的 IoU 0.806、P95 31.9 mm，可见面质量最差之一；
4. 因此在 P06·S1 上，"单候选 L2 通行、多候选 D2 通行"**不能归功于 Lux3D 的生成先验**——
   预演用的几何主要来自观测约束与壳层，而不是生成补出的那一面。

## 对主表的准入

按协议，`strict.pass = False` 的候选只能作诊断。当前状态：

- 正式可进入主表的 Lux3D 候选：**0 个**；
- 唯一保留生成隐藏面的 C1 也因可见面不达标而不能进；
- 若要取得"生成隐藏面有贡献"的证据，需要先修正生成输入链路（裁剪-相机对应、`aiPredictSize` 归一化）。

## 口径

本批不能声称"多候选提升判断能力"；能声称的只有"配准接线改变了决策、两种方案在该状态都通行"，
且这一通行结果来自观测约束几何。
