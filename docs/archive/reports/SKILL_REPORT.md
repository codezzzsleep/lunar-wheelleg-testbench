> **三句话结论**
> 1. 新增能力：任务条件 → 物理场景 → 训练 → 固定清单评估 → 陌生资产考核的完整闭环，

> 3. 陌生考核**未通过**：在未参与训练的家族上，学习后 0–1/8，与训练前无实质差别。

## 2. 技能定义（先冻结，再看结果）

- 场景：平地 + 通道（半宽 0.40 m），通道正中 1 个 Lux3D 生成障碍，
  横向宽度 0.50 m，两侧余量约 0.15 m（机器人宽约 0.30 m，**无法绕过**）。
- 初始条件：横向偏差 ±0.20 m、朝向 ±0.08 rad（按 seed 真实扰动，同组配对）。
- 障碍高度 0.085–0.095 m（约 1.0–1.1 倍轮半径）。
- **成功判据**：四轮全部越过**变换后几何**的远端（不是 manifest 半深）+ 0.10 m 净空，
  并在通道内**连续**稳定保持 1.0 s；中途退出通道/倾覆/回退都清零重计时。
- 失败分类：`tipped` / `out_of_bounds` / `time_limit`；接触与不接触分别记录。
- 家族划分：训练 `flat_slab / crate_lid / fallen_panel`，验证 `debris_plate / boulder`，
  考核 `cargo_crate / lander_leg`（互不重叠）。

## 4. 学了什么 / 失败在哪

- 学习到的是**通道对准 + 低速压过矮障碍**的组合：训练后 `out_of_bounds` 大幅减少，
  成功回合都带轮子接触（`contact_style=wheel`，首次接触约 2.8 s）。
- 失败种子的共同模式是**起步即横向出界**：稀疏的终态奖励给不出梯度。
  一次有明确假设的干预——加密集横向偏差惩罚（`r_lat = -0.3·|lat|`）——
  把 1/3 提升到 2/3（`runs/skill_v1` 对 `runs/skill_v2`），但仍有一个种子崩溃。
- 未训练初始化的方差极大（0.0 / 0.556），所以"训练前后"必须**同种子配对**比较，
  不能拿训练后最好的种子比未训练最差的种子。

## 5. 本轮改了哪些假设

| 假设 | 是否有干预证据 |
| --- | --- |
| 观测缺导航信息导致学不会横向纠偏 | **有**：补 nav 状态后同一任务出现 5.6%→66.7% |
| 中间截断 bootstrap 错误 | **有**：任务书反例实算一致（-2.7） |
| height 条件被覆盖 | **有**：修后三档物理高度不同 |
| 稀疏终态奖励导致部分种子无梯度 | **部分**：加密集横向惩罚后 1/3 → 2/3，但未彻底 |
| "前进奖励主导 / 延迟信用分配" | **仍是假设**：本轮没有做奖励消融实验来分离 |
| 生成几何更好或更差 | **无结论**：本轮没做 P/G 长跑，两组都没到可比较的稳定状态 |
