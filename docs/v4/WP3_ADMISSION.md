# WP3 准入标定（§2.4）

- 标定源：`runs/v3/stage008/truth_v2`；真值先验 + 平移 ±2 cm、缩放 0.9/1.1 扰动 + 两个坏对照（平移 15 cm、缩放 0.6）。
- 配置：`configs/v4_admission.json`（已冻结，不随批次调整）。
- 指标定义：
  - 尺度比 = 配准后候选世界高度 / V 壳层高度（不用 GLB 绝对缩放）；
  - 隐藏占比 = 候选体素落在 U 的比例；
  - 壳层相接 = 1 体素膨胀后候选触及的 V 壳层体素 / V 壳层体素数；
  - 空地侵入 = 候选体素落在已知空地（space==2）/ 候选体素数，硬上限 2%；
  - 轮廓冲突 = 可见掩码 IoU，只按标定容差判，不再用 IoU≥0.90 旧门槛。
- 真值先验：尺度 1.007、隐藏占比 0.964、壳层相接 0.940、侵入 0.27%、IoU 0.9955，通过。
- 坏对照：15 cm 平移 IoU 0.588、相接 0；0.6 缩放高度比 0.604、隐藏 0，均拒绝。
- 部分 ±2 cm / 1.1× 扰动会因侵入超过 2% 被拒；这是 §2.4 硬规则，不放宽。
