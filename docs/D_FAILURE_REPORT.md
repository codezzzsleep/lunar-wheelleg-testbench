# D1 CLIMB 最小失败报告（按 SPEC B6/D5 有限尝试规则）

- **结论**：CLIMB **未通过**；两条实现路径都未拿到“四轮在台上稳定保持 + 下降”。
  不把轮式助爬的 RL 称作“腿式搭台”。
- 场景：两块 5 cm 高、0.45 m 宽、错开且同后缘（x=2.35 m）的窄台；机器人 19.1264 kg /
  30.985 N；同一土壤与时间预算。

## 路径 A：准静态逐腿抬升

- 已搭台：FR / FL / RR；阻塞在 `RL_shift`。
- 证据：RL 支撑裕度在不同 run 为 **+10.2 / −9.6 / −13.6 mm**；移到最近的边或三角形内心
  都可能卸载一条支撑轮（曾出现 −168 mm）。
- 缺口：RR 落稳后，支撑三角形 FR/FL/RR 恰好缺左后角，而 CoM 偏左后；横向/前向
  重新准备也无法在保持三条支撑轮接触的同时把裕度稳定到 10 mm 以上。

## 路径 B：轮腿协同推进（最后一轮保持接触滚上）

- 已搭台：FR / FL / RR；RL 用 0.12 m/s 轮式助爬，成功到 x=1.2013、载荷 13.97 N。
- 阻塞在 `hold_all`：**FR 48.8%、FL 13.9%、RL 37.2%、RR 0%**，倾角 9.06°；
  机身落在 FR/FL/RL 三点，RR 悬空；下压 RR 3 cm 仍为 0。
- 缺口：**四轮保持**；没有进入下降。

## 处理

- 按 SPEC D5：如实标 CLIMB 未过，暂停依赖它的腿式展示，转到**已授权回退路径
