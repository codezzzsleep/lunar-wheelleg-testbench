# WP5 软土抬轮脱困报告（基线阶段）

- 问题：WHEEL_ONLY 在软土上是否明显卡住；SOFT_ESCAPE 是否值得实现。
- 软土参数：`configs/v4_soil_soft.json`（kc 250、kφ 50000、c 35 Pa、φ 21°、k_shear 0.03），
  比 nominal 明显更软；目前是全场地均匀软土探针，1.5 m 分区尚待接入。
- WHEEL_ONLY 10 s 实测：**前进 −1.976 m**（轮子打滑后退），机身高度 0.383 m 未翻，
  结局 time_limit；比“前进不到 0.1 m”更差，属于明显失去牵引。
- 更硬参数（kφ 60000）可前进 0.48 m，更软（kφ 40000）会翻车/下沉，说明工作点落在
  卡住但可恢复的区间附近。
- SOFT_ESCAPE：尚未实现；下一步按逐轮抬起/前移/放下实现，并在 3 个初态上验收。
- 未完成：1.5 m 软土分区、3 初态、每轮下陷/滑移记录、逃逸成功率。
