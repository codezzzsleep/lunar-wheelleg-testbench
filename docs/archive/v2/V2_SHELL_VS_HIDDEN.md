# 壳层几何 vs 生成隐藏面：同一状态、同一快照、同一预算

| 几何 | 来源 | 生成隐藏面 | 决策 | 真值结局 |
| --- | --- | --- | --- | --- |
| **A1（融合后）** | 观测壳层，`kept_ratio = 0` | **无** | **L2** | **通行** |
| **C1（融合后）** | 观测 + 生成隐藏面，`kept_ratio = 1.0` | **全部保留** | **D2** | **通行** |

两者都通行，但选择不同动作。

## 判读

1. **没有生成隐藏面也能通行**（A1 壳层几何）；
2. **保留生成隐藏面也通行**（C1），但动作从 L2 变成 D2；
3. 因此本状态上**生成先验没有把"不可行"变成"可行"**——只是改变了选择；
4. 这仍不能完全排除生成面在别的状态上的价值，但至少说明：
   **在 P06·S1，"能通行"这件事完全由观测壳层支撑**。

## 与本批研究问题的关系

任务书要求回答"Lux3D 是否在 2.5D 补平解决不了而参考可过的状态上取胜"。
P06·S1 的真值参考 L2 可过、2.5D 补平此前是 A0/失败，属于该子集；
但本状态的 Lux 结果（L2 或 D2）**都建立在不含生成隐藏面的几何上**，
所以不能算 Lux3D 取胜，只能算"观测约束几何足以支撑通行"。
