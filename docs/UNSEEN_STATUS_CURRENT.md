## 4. 月壤：逐轮参数真正隔离

关键认识：MuJoCo 对同优先级 geom pair 的摩擦**逐元素取最大**。
把土壤地面摩擦置 0 后，每个 geom 使用自己的值（轮=`mu_eff`、机身/岩石保留原值），
因此每轮上限互相独立、与接触遍历顺序无关。

实测 3 轮同时接触：μ = 0.01767 / 0.01708 / 0.02052（各不相同），地面 0.0。
`tests/test_soil_integration` 6 项覆盖：c=φ=0 无持续牵引、逐轮 μ 等于自身公式、
地面保持 0、reset 可复现、rigid 模式不改摩擦。

**边界不变**：几何下陷未实现（18 mm 是公式估计），未宣称实现 J–H 滑转。
