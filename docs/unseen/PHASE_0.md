## 观测（`scripts/observe.py`，已跑通）

输出：`rgb.png`、`depth.npy`、`mask.png`、`visible_points.npy`、`crop_raw.png`、`observation.json`。

实现要点与实际踩的坑：

1. **相机朝向**：MuJoCo 相机朝自身 −z。绕 +y 旋转 θ 后视线为 (−sinθ, 0, −cosθ)，
   要朝 +x 且下俯 |pitch| 必须 θ = −(90−|pitch|)。一开始写成 −pitch，结果相机朝后，画面全空。
2. **相机位置**：装在 `(0.30,0,0.06)` 时每根射线在 2 cm 处先命中机器人自身几何，
   掩码恒为空。改到 `(0.42,0,0.20)` 才能看到障碍。
3. **掩码**：MuJoCo 的 segmentation 通道编码在本机不可靠（2 通道、解码后出现 −257 等值），
   改为**逐像素射线**（1/2 分辨率 + 上采样），严格等价于"该像素是否先打到障碍"。
4. **反投影**：相机系 +z 取 −depth（朝 −z 看），再用 `cam_xmat` 转到世界。
