# 配准入口修复后的复测（P06·S1）

## 修复内容

1. **撤回**上一份报告的归因：`v2_register4.py` 把包围盒中心放到 z=0，石头被埋进地面；只搜 yaw 与 ±5% 尺度，
   没有复用 24 朝向。那次低 IoU **不能**说明候选与观测不符，只能说明"这套搜索没找到合适放置"。
2. 正式入口改为复用 `scripts/align24.py`（24 个保持手性的轴对齐旋转 × 尺度候选 × 粗 yaw，
   贴地 `z_min=0`，再用原生分辨率 `render_eval` 验收），并把结果接进 `v2_multi.prep`，之后才做融合。
3. 土壤标签改为显式记录（`point_labels = [corner_pp, corner_pm, corner_mp, corner_mm, nominal]`），
   选择器按标签读 nominal，不再用 `outcomes[0]` 猜。
