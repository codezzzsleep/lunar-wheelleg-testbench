> **注意：本报告的场景与任务定义已被本轮（单技能协议 v2）取代，**
> **其中的 P/G 结果仅作历史记录，不代表当前能力。** 最新协议与结果见
> [`SKILL_REPORT.md`](SKILL_REPORT.md)。


日期：2026-10-26　基线：`7347599`　数据：`runs/pg_v2/`、`runs/pg_v2_eval/`

> **结论：两种环境都没有表现出可用的训练收益，训练后的策略在共同测试集上
> 低于（部分种子显著低于）未训练策略。生成环境相对程序化环境没有优势。**
> 按任务书第十二节，这属于"两组都不能有效训练"，因此**不能据此否定生成环境的价值**——
> 共同瓶颈在训练环节，不在几何来源。

## 1. 协议（冻结于看测试结果之前）

| 项 | 设置 |
| --- | --- |
| 唯一变量 | 障碍几何来源（P 程序化 / G Lux3D 生成） |
| 地形 | 两组共用同一份 terrain 参数（逐场景相同，脚本断言） |
| 目标高度 | 两组共用同一阶梯 0.050 / 0.060 / 0.070 m，按 manifest 等比缩放 |
| 布局 | 同一套条件语法与采样规则（位置、横向偏移、yaw、数量） |
| 条件 | A 巡检区（平地）/ B 坡地（5°，起伏 0.03，坑 1×0.03）/ C 残骸通行段（3°，起伏 0.04，坑 1×0.04） |
| 场景数 | 每条件 8 训练 / 4 验证 / 4 测试 → 每组 24 / 12 / 12 |
| 家族划分 | 按 GLB 家族，训练/验证/测试互不重叠（脚本断言） |
| 机器人 | Go2W，观测 40 维本体感觉，动作 4 维残差（前腿/后腿偏移、轮速倍率、差速转向） |
| 算法 | PPO（numpy），lr 3e-4，clip 0.2，γ 0.99，λ 0.95，40k 控制步，种子 0/1/2 |
| 评估 | 共同清单 = P 留出 12 + G 留出 12 = 24 场景 × 3 episode_seed = **72 episode** |
| 口径 | deterministic（策略均值）与 stochastic（固定种子采样）并列报告，不挑选 |

## 2. 结果

### 2.1 共同测试集（72 episode / 每个策略）

| 策略 | det 成功率 | det 倾覆率 | stoch 成功率 | stoch 倾覆率 |
| --- | --- | --- | --- | --- |
| 未训练 seed0 | 0.375 | 0.583 | 0.306 | 0.667 |
| 未训练 seed1 | 0.583 | 0.167 | 0.278 | 0.167 |
| 未训练 seed2 | 0.417 | 0.042 | 0.014 | 0.528 |
| **未训练均值** | **0.458** | 0.264 | **0.199** | 0.454 |
| P_s0 | 0.417 | 0.375 | 0.500 | 0.306 |
| P_s1 | 0.458 | 0.292 | 0.222 | 0.292 |
| P_s2 | 0.000 | 0.042 | 0.000 | 0.347 |
| **P 均值** | **0.292** | 0.236 | **0.241** | 0.315 |
| G_s0 | 0.542 | 0.083 | 0.167 | 0.306 |
| G_s1 | 0.125 | 0.292 | 0.194 | 0.056 |
| G_s2 | 0.000 | 0.000 | 0.000 | 0.056 |
| **G 均值** | **0.222** | 0.125 | **0.120** | 0.139 |

### 2.2 怎么看这些数字

- **训练没有带来提升**：确定性口径上，未训练均值 0.458 高于 P 的 0.292 和 G 的 0.222。
- **随机口径**：P 0.241 略高于未训练 0.199，G 0.120 低于未训练。差异远小于种子间方差。
- **每组都有一个种子崩到 0**（P_s2、G_s2），两者都是 `out_of_bounds` 占绝大多数
  （P_s2 det 倾覆仅 0.042，G_s2 det 全部 72/72 出界）。这说明训练把策略推到了
  "沿路冲出去" 的方向，而不是越障。
- **P 与 G 的差距（0.292 vs 0.222）不能当作结论**：每格只有 3 个种子、单边崩溃就足以
  翻转排序；没有做显著性检验，也不做。

## 3. 观察与解释（分开写）

**观察**（数据支持）：
1. 两组训练后确定性成功率都低于各自初始化。
2. 崩溃种子以横向出界为主，不是倾覆。
3. G_s0 是唯一明显高于基线的单点（0.542），但同组另两个种子为 0.125 / 0.000，
   不能据此说 G 更好。

**解释**（假设，未单独验证）：
- 奖励里前进项（20×位移）在训练早期占主导，策略学会"往前冲"，而越障需要减速与
  对准，收益在数百步之后。这与观察 2 一致。
- 出界判据 `|y| > 0.45` 在障碍导致横向偏移时容易被触发；我们不通过放宽它来制造成功。
- 生成几何在低高度档（0.05–0.07 m）本身并不比方块更难，因此"几何来源"很可能不是
  当前瓶颈——瓶颈在训练与奖励设计。
