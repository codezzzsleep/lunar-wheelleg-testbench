## 2. 本轮结构改动：导航真正成为共享底座

- 学习器动作从 4 维降为 **3 维**（前腿偏移、后腿偏移、轮速倍率）；
  **第 4 维差速转向由底座产生**（`_steer_from_nav`，比例控制，增益 1.0 / 0.5）。
- 因此"零越障残差"基线 = 同一底座 + 不学习，与学习策略**同底座、同观测、同约束**。
- 底座验收：无障碍、固定通道半宽 0.42 m、20 个真实初态（横向 ±0.20 m、朝向 ±0.08 rad）
  → **安全到达 20/20 = 100%**（工程目标 90%）。
- 修掉一个真 bug：无障碍时"跑过终点即判出界"的兜底逻辑会在保持期内误触发，
  导致导航 0/20。修正后 20/20。

## 6. 可操作入口

```bash
.venv/bin/python scripts/app.py --port 8080
# 打开 http://127.0.0.1:8080
```

- 出题：任务 M/K、资产（缓存）、障碍高度、初始横向偏差、障碍横向位置、初态 seed。
- 考核：底座+零残差 / 底座+固定原语 / 已训练策略（自动发现 checkpoint）。
- 复盘：结局、通行方式、接触与首次接触、终态、完成线、失败阶段、下一道练习题建议、轨迹图。
- 不收费：页面只组装缓存资产，不触发任何生成请求；生成需在命令行显式 `--submit`。

## 7. 失败反馈 → 下一道题（规则，人工可复核）

页面里的建议由 `failure_hint()` 生成，规则透明：出界→加横向偏差练习；倾覆→降高度、
练低速接触；`bypass`→把障碍移到轮线上做单侧接触题；超时→查卡住位置。
**不是"自动理解失败机制"，也没有验证这些建议能提升泛化。**
